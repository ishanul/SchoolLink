# Task: Discovery and Problem Understanding

## Goal

Understand the real problem before proposing a solution.

Do not start with screens, database tables, or technology choices. Start with the people and the school communication problems they face.

## Work To Complete

Prepare a short write-up covering:

- How schools currently communicate with parents in Sri Lanka
- Problems with WhatsApp groups, paper notices, phone calls, verbal messages, and manual registers
- Problems faced by parents or guardians
- Problems faced by teachers
- Problems faced by school administrators
- Problems faced by students

## Product Name

The project currently uses SchoolLink as a working name.

Propose 3 possible product names and select 1 recommended name.

For each name, explain:

- Meaning
- Target audience fit
- Sri Lankan context fit
- Whether it sounds suitable for schools
- Any possible weakness or confusion

Avoid choosing a name only because it sounds modern. The name should make sense to schools, teachers, parents, and students.

## Expected Output

- 1-2 page problem analysis
- At least 5 key pain points
- At least 3 real-world examples or scenarios
- 3 name options
- 1 recommended name with justification
