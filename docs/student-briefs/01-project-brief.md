# Project Brief: School Communication Platform for Sri Lanka

## Context

Many schools in Sri Lanka rely on WhatsApp groups, printed notices, phone calls, and manual registers for school-parent communication. This can lead to missed notices, unclear assignment deadlines, duplicated admin work, and limited visibility for parents.

You are asked to design an MVP for a Sri Lanka-focused school-parent communication and academic visibility platform.

The final product name has not been decided. As part of your discovery work, propose a suitable name and explain why it fits the target users and local context.

The platform should connect:

- School administrators
- Teachers
- Parents or guardians
- Students, optionally with limited access

## Objective

Design a unified platform that helps schools:

- Improve communication
- Reduce paper-based and manual administration
- Help parents track relevant school updates
- Help students remain accountable for assignments and deadlines
- Support digital consent workflows
- Send useful reminders without overwhelming users

## Expected MVP Areas

You must decide what belongs in the MVP and what should be postponed. Consider these areas:

- Announcements
- Assignment tracking
- Smart notifications
- Digital consent forms
- Calendar or event visibility
- Basic dashboards
- Multilingual support
- Privacy and security

## Deliverables

Student group should produce:

- Proposed product name with justification
- Problem statement
- Target users
- Top 5 local pain points
- MVP feature list
- Out-of-scope feature list
- User roles and permissions
- Main user journeys
- Functional requirements
- Non-functional requirements
- Data entity list or ER diagram
- Basic wireframes
- Key risks and assumptions
- 10 acceptance criteria

## Discussion Questions

Be ready to defend your decisions:

- Why did you include each MVP feature?
- What did you intentionally leave out?
- How will you avoid overwhelming teachers?
- How will parents with limited digital literacy use the system?
- How will you protect student data?
- What happens if one parent has multiple children?
- What happens if one student has multiple guardians?
- How does the system behave when internet access is unreliable?
