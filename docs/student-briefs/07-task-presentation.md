# Task: Presentation and First Review

## Goal

Present the group's understanding of the problem and proposed direction.

The presentation should show your thinking, not only the final answer.

## Presentation Should Cover

- Problem understanding
- Product name and reasoning
- Target users
- MVP scope
- Out-of-scope decisions
- User roles and permissions
- Key workflows
- Draft requirements
- Initial data model
- Wireframes
- Risks, assumptions, and limitations

## Be Ready To Defend

Prepare to answer questions such as:

- Why is this problem important?
- Why did you include each MVP feature?
- Why did you postpone certain features?
- How will the system avoid notification spam?
- How will it reduce teacher workload?
- How will it protect student and parent data?
- How will it support Sri Lankan school realities?
- What is the biggest risk in your proposed solution?

## Submission Checklist

- Problem analysis document
- Product name options and recommendation
- MVP and out-of-scope list
- Role-permission matrix
- User stories
- User journey diagrams or descriptions
- Draft SRS
- ER diagram or data model
- Wireframes
- Presentation slides or document
