# SchoolLink

SchoolLink is a Sri Lanka-focused school communication and academic visibility platform concept for administrators, teachers, parents, and students.

The project is inspired by platforms such as Singapore's Parents Gateway, but the goal is not to copy an existing product. The goal is to understand local school communication problems and design a practical MVP for Sri Lankan schools.

## Project Status

This repository is currently in the discovery and requirements phase.

The student group should first focus on:

- Understanding the problem
- Identifying local school communication pain points
- Defining the MVP scope
- Proposing and justifying the product direction
- Preparing a draft Software Requirements Specification

Coding should begin only after the group has agreed on the MVP scope, user roles, main workflows, and data model.

## Core Problem

Many schools still rely on WhatsApp groups, printed notices, phone calls, and manual registers. This can create missed announcements, unclear homework deadlines, duplicated admin work, and limited visibility for parents.

SchoolLink aims to explore how a structured digital platform can reduce this communication gap.

## Expected MVP Areas

The first version may include:

- School and class announcements
- Assignment and homework tracking
- Digital consent forms
- Smart notifications and reminders
- Parent, teacher, and admin dashboards
- Optional limited student access
- Sinhala, Tamil, and English readiness

The final MVP scope must be proposed and defended by the student group.
